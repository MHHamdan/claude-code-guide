# .claueignore Patterns Library

`.claueignore` follows the same syntax as `.gitignore`. Files matched
here will not be indexed by Claude Code when it explores your project.

Templates:
- [Python / Data Science](python.claueignore)
- [Node.js / TypeScript](node.claueignore)
- [Monorepo](monorepo.claueignore)
- [ML / Large files](ml.claueignore)
- [Universal baseline](universal.claueignore)
