# Claude.ai Prompt Commands

These are prompt prefixes you can use in Claude.ai chat to control output format, thinking style, and tone. Unlike Claude Code (which operates on your codebase), these work in the claude.ai web/mobile interface.

**How to use:** Prepend the command to your prompt.

```
/brief explain how transformers work
/analyst review this architecture diagram: [paste]
/stepbystep debug this Python error: [paste]
```

Commands can be combined:
```
/brief /bullet summarize this paper: [paste]
/deepdive /data explain the tradeoffs of RAG vs fine-tuning
```
